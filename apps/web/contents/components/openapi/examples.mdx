`RequestExample` builds a request from the spec, with an auth placeholder, and shows it in cURL, JavaScript, Python, Go, Rust, Java, Kotlin or C#. A menu in the header switches language. Use `languages` to offer only some of them. `ResponseExample` shows an example body for each status code. If the spec has no example, one is generated from the schema.

The code comes from [`createCodeSample`](/docs/openapi/code-samples) in `@ariadocs/openapi`.
