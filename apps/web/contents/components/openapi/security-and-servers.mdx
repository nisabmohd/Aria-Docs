`OpenAPI.Security` shows what to send to authenticate, such as an `Authorization` header with a bearer token, or an API key header. When the spec allows several methods, they're listed with "or" between them.

`OpenAPI.Server` lists the base URLs. Variables in a URL, like `{region}`, are filled with their default values.

Both use the current endpoint's settings. You can pass `security` or `servers` to show something else.
