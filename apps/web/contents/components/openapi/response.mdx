Each status code gets a row, colored by type: success, redirect, client error or server error. Open a row to see the response headers and body fields. Write-only fields are hidden, since the server doesn't return them.

To render a single response with your own layout:

```tsx
<OpenAPI.Response response={operation.responses[0]}>
  <OpenAPI.Response.Status />
  <OpenAPI.Response.Description />
  <OpenAPI.Response.Content />
</OpenAPI.Response>
```
