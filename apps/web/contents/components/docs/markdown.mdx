Descriptions in an OpenAPI spec are Markdown, written by whoever wrote the spec. `Markdown` renders paragraphs, headings, lists, code, bold, italics and links.

It never renders raw HTML. Links are checked first, so a `javascript:` link becomes plain text. Links to other sites open in a new tab.

```tsx
import { Markdown } from "@ariadocs/components";

<Markdown>{operation.description}</Markdown>;
```
